- Before porting a daemon-level module, copy the current release binaries to `target/oldbin/`. Afterwards, diff stdout, stderr and exit code of old vs new across CLI cases and a daemonized lifecycle (start/test/reload/info/stop).
- As root, lifecycle tests need `WORKING_USER = root` in the test cfg, because `nobody` cannot chdir into /root.
- Never run `pkill -f target/release/plfs` inside a bg_run command: it matches the background shell's own command line and kills the task. Use `pkill -x plfsmaster` (exact process name) instead.
- rustfmt is not installed for the pinned nightly toolchain, so `cargo fmt` fails.
- Daemon mains are `Spec` tables over `plfscommon::daemon::run` (a safe port of main.c). argv is captured through `.init_array`, because processname rewrites the real contiguous argv block.
