Established migration pattern for polaris-fs:
- Port from the C original in `/tmp/moosefs-ref` (if present), NOT from the transpile — c2rust output is ~60-80% macro-expansion noise. (In practice the reference tree has been cloned to `target/ref/moosefs-ref` via `git clone --depth 1 --branch v4.59.2 https://github.com/moosefs/moosefs.git`.)
- Safe core in `#[deny(unsafe_code)] mod imp`; C ABI exports stay as thin boundary fns with SAFETY comments. Consumers link by symbol — never change exported signatures.
- C quirks are behavior: preserve exact overflow/wrapping, threshold comparisons (`<` vs `<=`), timestamp stamping, and refcount protocols. Write reference tests for parsers/serializers against C semantics.
- Genuine C-only modules (kernel callbacks, process bootstrap) become **annotated boundaries**: module-header justification, not forced rewrites (see mfs_fuse.rs, plfsmount.rs, plfscommon/sockets.rs).
