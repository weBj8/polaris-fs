# PolarisFS

PolarisFS is restarting as a clean-room distributed filesystem project aligned with
IBM Storage Scale's publicly observable administration model. Its management commands
will use the `pl*` prefix rather than IBM's `mm*` prefix.

## Compatibility objective

The project will independently implement and test equivalent user-facing command
workflows, operational behavior, recovery properties, and performance characteristics.
IBM source code, binaries, and documentation text are not copied into this repository.

## Status

No implementation exists yet. The next work is defined in [ROADMAP.md](ROADMAP.md).
